# Pri’s Cozy Crochet

Complete static frontend — latest version.

## Files
- index.html: page layout
- style.css: responsive styles and animations
- app.js: carousel, typing animation, bag, wishlist, search and filters
- assets/: all four local WebP images

## Preview
Extract the ZIP and open index.html in a browser. No installation or build is needed.

## GitHub
Upload the extracted contents to your repository root, with index.html at the root and the assets folder beside it. Enable GitHub Pages for the branch and root folder you uploaded. Upload the extracted files rather than the ZIP itself.

All asset paths are relative, so the website works on a GitHub Pages project URL.

## Current scope
This is a frontend preview. Images and prices are samples. Bag and wishlist are browser-local. Checkout, payments and live support are not connected. Under ₹250 currently has no sample products. Support opens help topics.

## Editing
Update product data in app.js and matching product cards in index.html. Replace assets with your own product photos when ready. Do not rename image files without updating their references.
